About

How the model works

A stats-based predictor — not a deep learning model. It cannot see pixels. What it CAN do is extract signal from where a URL came from in your pipeline.

The training data

Built from — historical QC records. A record is labeled Fail when rejected_comment is non-null, and Pass otherwise.

Validation

20% held-out test split (stratified). AUC = 0.994. At the default 5% threshold the model catches 90% of fails with 60% precision.

Why is AUC so high? In this dataset, failing images cluster heavily in one S3 bucket (spyne-desktop-app), which is itself a strong signal. The model exploits that. New domains never seen before get scored at the base rate and marked Unknown.

What it cannot do

It does not look at pixels. A pristine image hosted on a "fail-prone" URL will be predicted Fail, and a defective image on a clean URL will be predicted Pass.

For real image-content prediction you need a vision model trained on the actual frames — a much heavier project. This tool is the cheap, useful approximation.
